# ComfierUI Support

For help with ComfierUI, bug reports, or compatibility issues, please use the Issues section of this repository.

https://github.com/ComfierUI/ComfierUI-Android/issues

When reporting a problem, please include:

- ComfierUI version
- Android version
- Device model
- ComfyUI version, when relevant
- A description of the issue
- Steps to reproduce the problem

Screenshots may be included when helpful.

Please do not post:

- Private IP addresses
- API keys
- Passwords
- Authentication tokens
- Other private or sensitive information

For privacy-related questions, see:

https://github.com/ComfierUI/ComfierUI-Android/blob/main/PRIVACY.md
